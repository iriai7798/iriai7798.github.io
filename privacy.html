Hub 개인정보처리방침

시행일: 2026-11-17

1. 수집·이용하는 정보

Hub는 사용자가 직접 입력한 일정, 할 일, 메모와 첨부파일을 저장합니다. 사용자가 Google 계정 연결을 선택하면, 선택한 Google 캘린더의 일정 정보(제목, 시간, 설명 등)를 읽고 쓰기 위해 Google 캘린더 접근 권한(calendar.events, calendar.calendarlist.readonly)을 사용합니다.

2. 정보의 저장과 보관

모든 데이터는 운영자가 개인적으로 관리하는 서버에만 저장되며, 사용자별로 분리됩니다. Google에서 받은 인증 정보(토큰)도 해당 사용자의 데이터 영역에만 저장됩니다.

3. 제3자 제공 및 사용 제한

Hub는 Google 사용자 데이터를 광고, 판매, 분석, 제3자 제공 등에 사용하지 않으며, 일정 동기화라는 앱 본연의 기능을 제공하는 용도로만 사용합니다. Hub의 Google API 데이터 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 삭제

사용자는 앱에서 Google 연결을 해제하거나, Google 계정 설정(보안 → 타사 앱 액세스)에서 권한을 철회할 수 있습니다. 계정과 데이터 삭제를 원하면 아래 연락처로 요청해 주세요.
